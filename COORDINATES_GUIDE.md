# Руководство по определению координат для построения маршрутов

## Что нужно определить с изображения плана этажа

Для корректной работы алгоритма построения маршрутов необходимо определить следующие координаты (в пикселях):

## 1. Координаты центров кабинетов

**Что это:** Точка в центре каждого кабинета на плане этажа.

**Как определить:**
- Откройте изображение плана этажа в графическом редакторе (например, Paint, GIMP, или онлайн-редактор)
- Наведите курсор на центр каждого кабинета
- Запишите координаты X и Y (в пикселях)

**Пример:**
- Кабинет "101" - центр кабинета: X=97, Y=725
- Кабинет "102" - центр кабинета: X=96, Y=554
- И т.д.

## 2. Координаты дверей кабинетов (точки входа в коридор)

**Что это:** Точка, где дверь кабинета выходит в коридор. Это критически важно!

**Как определить:**
- Найдите дверь каждого кабинета на плане
- Определите точку, где дверь "соединяется" с коридором
- Запишите координаты этой точки

**Важно:** 
- Дверь должна быть в месте, где действительно есть проход в коридор
- Обычно дверь находится на границе кабинета и коридора
- Для кабинетов в левом ряду (101-106) двери обычно справа от кабинета
- Для кабинетов в нижнем ряду (Охрана, Гардероб и т.д.) двери обычно снизу или спереди

**Пример:**
- Дверь кабинета "101" (door_101) - точка входа в коридор: X=150, Y=725
- Дверь кабинета "Охрана" (door_Охрана) - точка входа в коридор: X=198, Y=750

## 3. Координаты точек коридора (узлы навигации)

**Что это:** Точки в коридорах, которые соединяют разные части здания. Это узлы графа навигации.

**Как определить:**
- Найдите основные коридоры на плане:
  - **Вертикальный левый коридор** (вдоль кабинетов 101-106)
  - **Горизонтальный нижний коридор** (вдоль Охрана, Гардероб, Канцелярия и т.д.)
  - **Центральный коридор** (соединяет левый коридор с правой частью)
- Определите ключевые точки в каждом коридоре:
  - Пересечения коридоров
  - Повороты
  - Точки соединения с дверями

**Пример точек коридора:**
- `corridor_left_top` - верхняя точка левого коридора (около кабинета 101)
- `corridor_left_1` - точка между кабинетами 101 и 102
- `corridor_left_2` - точка между кабинетами 102 и 103
- И т.д.

**Важно:** 
- Точки коридора должны быть в центре коридора (не в стенах!)
- Точки должны логично соединять двери кабинетов
- Точки должны образовывать связную сеть (можно пройти от любой точки до любой другой)

## 4. Структура связей (граф)

**Что это:** Определение, какие точки связаны между собой (какие двери ведут в какие коридоры, как коридоры соединяются между собой).

**Как определить:**
- Для каждого кабинета: определите, в какой коридор выходит его дверь
- Для каждого коридора: определите, какие двери к нему ведут
- Определите, как коридоры соединяются между собой (пересечения, переходы)

## Инструменты для определения координат

### Вариант 1: Python скрипт (рекомендуется) ⭐
В проекте есть готовый скрипт `get_coordinates.py`:

1. Убедитесь, что план этажа сохранен в `floorplans/floor_1.png` (или другой этаж)
2. Запустите скрипт:
   ```bash
   python get_coordinates.py floorplans/floor_1.png
   ```
3. Кликайте на изображении - координаты будут выводиться в консоль
4. Записывайте координаты для каждой точки

**Преимущества:** автоматический пересчет координат при масштабировании, удобный интерфейс

### Вариант 2: Paint (Windows)
1. Откройте изображение в Paint
2. Наведите курсор на нужную точку
3. Внизу окна Paint вы увидите координаты (X, Y)

### Вариант 3: GIMP
1. Откройте изображение в GIMP
2. Наведите курсор на нужную точку
3. Координаты отображаются внизу окна

### Вариант 4: Онлайн-редакторы
- photopea.com
- pixlr.com
- В большинстве редакторов координаты отображаются при наведении курсора

## Использование шаблона

В проекте есть файл `coordinates_template.txt` - используйте его для заполнения координат:

1. Откройте `coordinates_template.txt`
2. Заполните все координаты по порядку
3. После заполнения перенесите данные в `pathfinder.py`

## Пример структуры данных

После определения всех координат, они должны быть записаны в `pathfinder.py` в формате:

```python
COORDS_FLOOR_1 = {
    # Кабинеты (центры)
    "101": (97, 725),
    "102": (96, 554),
    # ... остальные кабинеты
    
    # Двери
    "door_101": (150, 725),  # Дверь кабинета 101
    "door_102": (150, 554),  # Дверь кабинета 102
    # ... остальные двери
    
    # Точки коридора
    "corridor_left_top": (180, 725),
    "corridor_left_1": (180, 650),
    # ... остальные точки коридора
}
```

## Чек-лист для проверки

После определения всех координат проверьте:

- [ ] Координаты всех кабинетов определены
- [ ] Координаты всех дверей определены
- [ ] Координаты точек коридора определены
- [ ] Двери находятся в коридорах (не в стенах!)
- [ ] Точки коридора находятся в центре коридоров
- [ ] Граф связей правильно отражает структуру здания
- [ ] Можно построить путь от любого кабинета до любого другого

## Типичные ошибки

1. **Двери в стенах** - двери должны быть в коридоре, а не в стене кабинета
2. **Точки коридора в стенах** - точки должны быть в центре коридора
3. **Неправильные связи** - проверьте, что граф правильно отражает структуру здания
4. **Отсутствие связей** - убедитесь, что все коридоры соединены между собой

## Рекомендации

1. Начните с определения координат кабинетов
2. Затем определите координаты дверей (это самое важное!)
3. Затем определите точки коридора
4. Проверьте граф связей
5. Протестируйте на нескольких маршрутах

## Если путь не находится

Если алгоритм не может найти путь между кабинетами, проверьте:

1. Существуют ли координаты для обоих кабинетов
2. Есть ли путь в графе (можно ли дойти от одного кабинета до другого через граф)
3. Правильно ли определены координаты дверей и коридоров
4. Все ли связи в графе двусторонние (если A соединен с B, то B должен быть соединен с A)
