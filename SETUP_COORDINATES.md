# Быстрая инструкция по настройке координат

## 🚀 Быстрый старт

### Шаг 1: Определите координаты

**Вариант A (рекомендуется):** Используйте скрипт
```bash
python get_coordinates.py floorplans/floor_1.png
```
Кликайте на изображении для получения координат.

**Вариант B:** Используйте Paint/GIMP
- Откройте `floorplans/floor_1.png` в редакторе
- Наведите курсор на нужную точку
- Запишите координаты (X, Y)

### Шаг 2: Заполните шаблон

1. Откройте `coordinates_template.txt`
2. Заполните все координаты:
   - ✅ Центры кабинетов
   - ✅ Двери кабинетов (точки входа в коридор)
   - ✅ Точки коридора

### Шаг 3: Перенесите в код

1. Откройте `pathfinder.py`
2. Найдите словарь `COORDS_FLOOR_1` (строка ~10)
3. Замените координаты на данные из шаблона

### Шаг 4: Проверьте

1. Запустите бота: `python main.py`
2. Протестируйте построение маршрута между кабинетами
3. Если путь не находится - проверьте координаты дверей и коридоров

## ⚠️ Частые ошибки

1. **Двери в стенах** → Двери должны быть в коридоре!
2. **Точки коридора в стенах** → Точки должны быть в центре коридора!
3. **Неправильные связи** → Проверьте граф в `GRAPH_FLOOR_1`
